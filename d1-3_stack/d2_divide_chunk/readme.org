(分割統治とも訳されますが，各個撃破がしっくりきます)
が基本戦略です．
でもちっちゃいのが積み重なってくると，
知識が干渉し始めて混乱します．
整理が必要になります．
整理のコツを言葉で表すとchunkingとdeja vuです．
chunkingはまとまった知識を覚える人間の癖を
心理学者が解き明かした知恵です．
それをまとめる時には
deja vuで示したようにコトバで概念をまとめます．
