1. とっかかりはHyperCard

HyperCardっていう面白いソフトが初期のMacには無料でついてました． これは，

an essential software construction kit that belonged in the hands of everday users

とすることを目的としてBill Atkinsonによって1987年ごろに開発されました． GUIアプリの基本は全て入っていたのですが， その派生として登場するいくつものアプリ (web browser, wiki, explorer, ppt, idea processor) が，万人が使える仕様へ変貌する課程で， 多くのいいところが削がれていきました． この授業では，院生，卒研生に利用してもらえる Mock-Upを作りながら"HyperCard"のコンセプトを 理解してもらう予定です．

HyperCardはカードをまとめた"Stack"を Floppy Diskに入れて交換(販売)してました． まだInternetがなかったんですよ． 皆さんにはGithubを通してStackにアクセスしてもらいます．
