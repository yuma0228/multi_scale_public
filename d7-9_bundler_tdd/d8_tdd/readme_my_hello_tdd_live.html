2. Turn 2 : Minitestのカラー表示を相談

2.1. user => Bob

green とかredを実感するために，minitestをcolorfulにするlibはありますか？

2.2. codex => Raphael

あります．おすすめは ​minitest-reporters​ です．成功を緑，失敗を赤で表示でき，テスト名も見やすくなります．

​Gemfile​ に追加します． 

gem "minitest-reporters", group: :test

インストールします． 

bundle install

​test/test_helper.rb​ の末尾に追加します． 

require "minitest/reporters"

Minitest::Reporters.use!(
  Minitest::Reporters::DefaultReporter.new(color: true)
)

実行はこれまでどおりです． 

bundle exec rake test

もっと簡単な選択肢として，赤・緑表示に特化した ​minitest-rg​ もあります．ただ，表示形式を後から変更できるため，授業用には ​minitest-reporters​ が使いやすいと思います．​minitest-rg​ は，より小さく単純な選択肢です．

4. Turn 4 : greetingのNameErrorを診断

4.1. user => Bob

 bundle exec exe/my_hello
bundler: failed to load command: exe/my_hello (exe/my_hello)
/Users/bob/Desktop/lecture_26f/multi_scale/d7-9_bundler_tdd/d8_tdd/my_hello/lib/my_hello.rb:12:in '<module:MyHello>': undefined local variable or method 'greeting' for module MyHello (NameError)

  greeting
  ^^^^^^^^

とのエラーが出ます．なぜ？

4.2. codex => Raphael

原因は，次の ​def greeting​ が ​MyHello​ モジュールのインスタンスメソッドとして定義されるためです． 

module MyHello
  def greeting
    puts "Hello."
  end

  greeting # MyHello自身にはこのメソッドがない
end

​MyHello.greeting​ として使えるモジュールメソッドにするには，次の形が分かりやすいです．

​lib/my_hello.rb​： 

module MyHello
  class Error < StandardError; end

  def self.greeting
    puts "Hello."
  end
end

​exe/my_hello​： 

#!/usr/bin/env ruby

require "my_hello"

MyHello.greeting

テストも，ファイルの再読み込みではなくメソッドを直接検証できます． 

def test_it_outputs_hello
  assert_output("Hello.\n") do
    MyHello.greeting
  end
end

この構成なら，​require "my_hello"​ しただけでは表示されず，​MyHello.greeting​ を呼んだときだけ ​Hello.​ が表示されます．
