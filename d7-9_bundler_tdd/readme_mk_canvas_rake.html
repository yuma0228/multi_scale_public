1.2. codex => Raphael

作成しました．

  • mk_canvas.rake
  • 生成確認済みの dir_node_edge.yaml

実行方法は次のとおりです． 

cd /Users/bob/Desktop/lecture_26f/multi_scale/d7-9_bundler_tdd
rake -f mk_canvas.rake mk_canvas

処理内容は次の順序です．

  1. 深さ2までのHTMLを探索する
  2. ディレクトリ階層を保持したYAMLを生成する
  3. ​hc view​でノード配置を編集する
  4. ​.semi_lattice/semi_lattice.yaml​から​canvas.html​を生成する
  5. 完成したCanvasを表示する

現在の構成について，1ルート，3ディレクトリ，9 HTML，12エッジになることを検証済みです．最後の表示を省略する場合は次を使用できます． 

OPEN=0 rake -f mk_canvas.rake mk_canvas

探索階層は，例えば​LEVEL=3​のように変更できます．
